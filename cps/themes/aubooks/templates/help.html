Помощь по сайту

Регистрация

Регистрация на AU-Books доступна только по приглашению.

  1. Откройте письмо «Приглашение в AU-Books».
  2. Перейдите по ссылке из письма.
  3. На странице «Зарегистрировать новую учётную запись» заполните:
    • «Имя пользователя»;
    • «Адрес электронной почты»;
    • «Пароль»;
    • «Подтвердите пароль».
  4. Нажмите «Зарегистрироваться».
  5. После регистрации войдите на сайт.

Вход на сайт

  1. Нажмите «Логин» в верхней части страницы.
  2. Введите «Имя пользователя».
  3. Введите «Пароль».
  4. Нажмите «Логин».

Флажок «Запомнить меня» позволяет не вводить логин и пароль при каждом посещении сайта.

Если забыли пароль

  1. Откройте страницу «Логин».
  2. В поле «Имя пользователя» введите своё имя пользователя.
  3. Нажмите «Забыли пароль ?».
  4. Новый пароль будет отправлен на адрес электронной почты, указанный в вашей учётной записи.

Пароль в поле «Пароль» для этого вводить не нужно.

Изменить пароль

  1. В верхней части сайта нажмите на своё имя пользователя.
  2. В поле «Пароль» введите новый пароль.
  3. Нажмите «Сохранить».

Изменить адрес электронной почты

  1. Нажмите на своё имя пользователя.
  2. Измените поле «Адрес электронной почты».
  3. Нажмите «Сохранить».

На этот адрес отправляется новый пароль при его восстановлении.

Найти книгу

В верхней части страницы находится поле «Поиск в библиотеке».

  1. Введите название книги, фамилию автора или несколько слов.
  2. Нажмите «Поиск».
  3. Нажмите на название нужной книги в результатах.

Расширенный поиск

Нажмите «Расширенный поиск» рядом с обычным поиском.

Можно искать по полям «Название книги», «Автор», «Издатель», «Опубликовано от», «Опубликовано до», «Теги», «Серии», «Языки», «Расширения» и другим параметрам.

После заполнения нужных полей нажмите «Поиск».

Найти книгу по жанру

  1. В левой части сайта нажмите «Все жанры».
  2. Выберите нужную категорию.
  3. Выберите жанр.
  4. Нажмите на название книги.

Скачать электронную книгу

  1. Откройте страницу книги.
  2. Нажмите «Скачать книгу».
  3. Если книга доступна в нескольких форматах, выберите нужный формат.

Для скачивания необходимо войти на сайт.

Озвучить книгу

Если готовой аудиокниги ещё нет:

  1. Откройте страницу книги.
  2. Нажмите «Озвучить».
  3. Книга будет поставлена в очередь.

После этого кнопка будет показывать текущее состояние:

  • «В очереди» — книга ожидает озвучивания.
  • «Озвучивается…» — аудиокнига создаётся.
  • «Скачать аудиокнигу» — аудиокнига готова.
  • «Озвучить повторно» — предыдущая попытка завершилась ошибкой, озвучивание можно запустить ещё раз.

Проверить состояние озвучивания

  1. Нажмите «Задания» в верхней части сайта.
  2. Откроется страница «Озвучивание».

В таблице отображаются книга, статус, время добавления и обновления, размер готового файла, длительность и ошибка, если она возникла.

Возможные статусы:

  • «В очереди» — ожидает обработки.
  • «Озвучивается…» — обрабатывается.
  • «Готово» — аудиокнига готова.
  • «Ошибка» — озвучивание завершилось ошибкой.
  • «Отменено» — озвучивание отменено.

Для готовой книги в колонке «Действие» доступна кнопка «Скачать аудиокнигу».

При ошибке или отмене доступна кнопка «Открыть книгу».

Скачать готовую аудиокнигу

Готовую аудиокнигу можно скачать двумя способами.

Со страницы книги:

  1. Откройте книгу.
  2. Нажмите «Скачать аудиокнигу».

Через список заданий:

  1. Нажмите «Задания».
  2. Найдите книгу со статусом «Готово».
  3. Нажмите «Скачать аудиокнигу».

Прослушать книгу в браузере

Если на странице книги есть кнопка «Прослушать в браузере»:

  1. Нажмите «Прослушать в браузере».
  2. Если доступно несколько аудиоформатов, выберите нужный.

Если кнопки «Прослушать в браузере» нет, но есть «Скачать аудиокнигу», книгу нужно сначала скачать.

Создать книжную полку

  1. В левой части сайта нажмите «Создать полку».
  2. Укажите название полки.
  3. Сохраните её.

Чтобы добавить книгу на существующую полку:

  1. Откройте страницу книги.
  2. Нажмите «Добавить на книжную полку».
  3. Выберите нужную полку.

Выйти с сайта

Нажмите «Выход» в верхней части страницы.
