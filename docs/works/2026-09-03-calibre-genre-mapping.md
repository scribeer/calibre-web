# 2026-09-03: Canonical AU-Books Genre Mapping

## Цель

Создать единый source of truth (`genre_mapping.tsv`) для нормализации тегов Calibre перед миграцией. Каждый из 1,316 уникальных тегов в metadata.db получает:
- canonical русское название;
- верхнеуровневую категорию (из существующих 21);
- классификацию;
- уровень уверенности.

## Формат TSV

```
raw_tag	canonical_tag	parent_category	classification	confidence	book_count	notes
```

- Табуляция как разделитель
- UTF-8
- Комментарии в `notes`
- Строго 7 колонок
- Нет duplicate raw_tag
- Нет пустого canonical_tag для high-confidence genre_code

## Порядок следующих шагов

1. Пользователь утверждает `genre_mapping.tsv`
2. Создаётся `normalize_tags.py` — функция нормализации для pipeline
3. Встраивается в `1au-prepare_book.py` перед `calibredb add`
4. Создаётся `migrate_tags.py` — массовая миграция через `calibredb set_metadata`
5. Запуск dry-run на реальных данных
6. Запуск миграции (batch по 100 книг)
7. Обновление Calibre-Web — упрощение `aubooks_genres.py`
8. Обновление URL — пересчёт child genre URLs
