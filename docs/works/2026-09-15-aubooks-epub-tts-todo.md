# EPUB TTS для AU-Books

## Статус
Будущая задача. Реализация НЕ начата.

## Приоритет
Высокий — функциональный bug.

## Проблема
Книги в формате EPUB не озвучиваются через TTS в AU-Books.

## Цель
Обеспечить полную цепочку озвучивания EPUB-книг:
EPUB-файл → получение файла → извлечение текста → нормализация/подготовка текста → TTS → создание аудио → публикация/OpenDrive.

## Этапы диагностики и реализации

### 1. Получение файла
- Проверить, как AU-Books получает EPUB-файл из библиотеки Calibre.
- Убедиться, что путь/URL к EPUB доступен для TTS-worker.
- Проверить права доступа и изоляцию dev/prod.

### 2. Извлечение текста
- Проверить используемую библиотеку для чтения EPUB (e.g., ebooklib, zipfile + lxml).
- Проверить обработку DRM-free EPUB.
- Проверить извлечение текста из HTML/XHTML сегментов.
- Проверить порядок текста (spine, reading order).

### 3. Нормализация/подготовка текста
- Удаление HTML-тегов.
- Удаление служебных блоков (notes, footnotes, TOC).
- Нормализация пробелов и переносов.
- Обработка скриптов/стилей, встроенных в HTML.
- Разбиение на фрагменты, подходящие для TTS.

### 4. TTS
- Проверить интеграцию с TTS-движком (собственный remote TTS, edge-tts, и т.д.).
- Проверить передачу текста в TTS.
- Проверить обработку ошибок и retry.

### 5. Создание аудио
- Проверить сборку аудиофрагментов в файл.
- Проверить формат выходного файла (mp3, m4a, и т.д.).
- Проверить битрейт, метаданные и обложку.

### 6. Публикация/OpenDrive
- Проверить загрузку готового аудио в OpenDrive.
- Проверить обновление статуса audiobook в базе.
- Проверить доступность аудио для пользователя.

## Связанные файлы
- `cps/tts_dispatcher.py` — диспетчеризация TTS.
- `cps/tasks/convert.py` или аналогичные worker-файлы.
- `cps/aubooks_audio.py` / `cps/aubooks_tts_transport.py` — AU-Books TTS.
- `cps/db.py` — модели Book, Data, formats.
- `cps/admin.py` — UI генерации аудио.

## Риски
- Разные структуры EPUB могут требовать разной обработки.
- Большие EPUB могут превышать лимиты памяти/времени.
- Необходимость поддержки не-латинских текстов.
