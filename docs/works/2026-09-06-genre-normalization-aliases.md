# Нормализация жанров: case-insensitive lookup + EXTRA_ALIASES

## Цель
Уменьшить количество тегов в «Другие жанры» за счёт нормализации регистра и явных aliases.

## Что изменено

### `cps/aubooks_genres.py`
- Добавлен `_LABEL_GENRES_NORMALIZED` — словарь с case-folded ключами для поиска русских меток независимо от регистра
- Добавлен `EXTRA_ALIASES` — 16 явных соответствий тег → Flibusta-код
- Добавлен `_ALIAS_GENRES` — резолвленные aliases
- Обновлён `MAPPED_TAG_NAMES` — включает normalized + alias имена
- `genre_for_tag()` теперь проверяет 4 уровня: GENRES → _LABEL_GENRES → _LABEL_GENRES_NORMALIZED → _ALIAS_GENRES

### `tests/test_aubooks_genres.py`
- Новый класс `AubooksCaseInsensitiveLookupTest` — 12 тестов (13 с subtests)
- Покрытие: case-insensitive русских labels, все ключевые aliases, unknown tag fallback
