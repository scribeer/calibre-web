# Упрощение страницы заданий аудиокниг
## Цель
Сделать страницу `/tasks` в теме AU-Books компактной страницей состояния озвучивания без штатной таблицы задач Calibre-Web.
## Что изучено
- AU-Books override `tasks.html` и подключение Bootstrap Table.
- Формат данных endpoint `/ajax/tts-jobs`.
- Клиентское обновление таблицы и форматирование значений после polling.
## Изменённые файлы
- `cps/themes/aubooks/templates/tasks.html`.
- `tests/test_aubooks_audio.py`.
- `docs/works/2026-09-09-simplify-audiobook-tasks-page.md`.
## Что изменено
- Заголовок страницы заменён на «Озвучивание» только в теме AU-Books.
- Штатная таблица Calibre-Web удалена из AU-Books шаблона, backend native tasks не изменён.
- Оставлена только TTS-таблица с polling каждые 5000 мс.
- Даты форматируются в локальном часовом поясе браузера как `ДД.ММ.ГГГГ ЧЧ:ММ`.
- Название книги стало ссылкой, автор выводится второй строкой.
- Для готовых записей выводится ссылка «Скачать аудиокнигу», для ошибок — «Открыть книгу».
- Пустые поля и отсутствующие действия отображаются знаком «—».
- Динамические title, author и error экранируются перед вставкой в таблицу.
## Тесты
- `python3 -m unittest tests.test_aubooks_audio -v`.
- Проверка DEV `/tasks` и `/ajax/tts-jobs`, включая запись `book_id=10`.
## Известные ограничения
- В TTS pipeline нет числового прогресса, поэтому показываются только реальные статусы.
- Проверка интерфейса выполняется на DEV; production не изменялся.
